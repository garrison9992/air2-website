Usage Instructions (English)

After installation, please go to your phone's Settings and enable the following permissions to ensure proper alarm notifications:

• Notifications: Allow notifications so alarms and reminders arrive on time.

• Microphone: Allow microphone access for voice input and recording.

• Battery Optimization: Disable battery optimization to prevent the app from background sleep.

• Background Activity: Allow background activity to ensure real-time reminders.

Инструкция по использованию (Русский)

После установки перейдите в Настройки телефона и включите следующие разрешения для корректной работы напоминаний:

• Уведомления: Разрешите уведомления, чтобы будильники и напоминания приходили вовремя.

• Микрофон: Разрешите доступ к микрофону для голосового ввода.

• Оптимизация батареи: Отключите оптимизацию батареи, чтобы приложение не выгружалось в фоне.

• Фоновая активность: Разрешите работу в фоне для стабильной работы таймера.

使用说明 (中文)

安装后，为了确保闹铃与提醒正常工作，请前往手机“设置”界面开启以下权限与配置：

• 通知权限：允许应用发送通知，确保闹铃准时送达。

• 麦克风权限：允许使用麦克风，以支持语音输入。

• 关闭电池优化：防止系统在后台强制休眠应用。

• 允许后台活动：保障定时提醒机制的实时性与稳定性。
